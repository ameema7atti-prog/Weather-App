# Weather Forecasting App 🌤️

A dynamic React weather application built for **Project 2** of the **Syntecxhub Web Development Internship**[cite: 32, 34]. This application allows users to search for real-time weather conditions and view a 5-day temperature forecast for any city worldwide using external API integrations[cite: 34].

## 🚀 Features
* **Real-time Weather Data:** Fetches current temperature, location details, and wind speed using Open-Meteo API[cite: 34].
* **5-Day Forecast:** Displays daily high and low temperatures for upcoming days[cite: 34].
* **City Search & Geocoding:** Automatically translates city names into geographical coordinates using Open-Meteo Geocoding API.
* **Error Handling:** Gracefully displays user-friendly error messages if a city is not found or API requests fail[cite: 34].
* **React `useEffect` Hook:** Handles asynchronous data fetching whenever a user searches for a new location[cite: 34].
* **Interactive UI:** Responsive, clean layout styled with inline modern CSS components[cite: 34].

## 🛠️ Tech Stack
* **Frontend:** React.js (Hooks), JavaScript (ES6+), HTML5, CSS3[cite: 34]
* **APIs Used:** Open-Meteo Geocoding API & Open-Meteo Forecast API
* **Hooks Used:** `useState`, `useEffect`[cite: 34]
